Quelles informations réunir avant l’assessment

Le formulaire prend une dizaine de minutes si vous avez ceci sous la main.

Le formulaire est court par choix. Ce qui le rend long, c’est de devoir aller chercher les réponses pendant qu’on le remplit. Voici ce qu’il demande, pour que vous puissiez le rassembler avant.

Sur l’organisation

  • Nom, site web, pays d’établissement, effectif approximatif.
  • Si vous proposez vos produits ou services à des utilisateurs situés dans l’UE.
  • Une adresse professionnelle pour la livraison.

Sur chaque système d’IA

C’est le bloc qui demande de la préparation. Pour chacun:

  • Ce qu’il fait, en une ou deux phrases, et qui le développe ou le fournit.
  • Si une personne interagit directement avec lui (chat, voix, assistant).
  • S’il génère ou manipule du texte, de l’audio, de l’image ou de la vidéo.
  • Si vous le mettez sur le marché sous votre propre nom ou marque.
  • S’il a été mis sur le marché avant le 2 août 2026.
  • Si ses sorties portent un marquage lisible par machine (métadonnées, filigrane, signal de provenance).

Sur ce que vous annoncez déjà

Si vous informez déjà vos utilisateurs, copiez la formulation exacte et dites où elle apparaît et à quel moment l’utilisateur la voit. Un texte existant qui fonctionne économise une recommandation.

Ce que nous ne demandons pas

Ni clés d’API, ni identifiants, ni données personnelles de vos utilisateurs finaux, ni code source, ni secrets commerciaux. Si une question vous semble aller par là, ne répondez pas: elle n’est pas de nous.

Une question précise

Le formulaire finit par une case libre. Une question précise — « notre agent vocal doit-il l’annoncer avant le premier mot ? » — change ce que le rapport détaille.
